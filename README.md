## 📌 О проекте

**CLI Task Manager** — консольная утилита для управления личными делами прямо из терминала. Проект разработан с упором на чистую модульную архитектуру, обработку краевых случаев (Edge Cases) и автономность без использования сторонних библиотек.

### ✨ Ключевые возможности:
- ➕ **Добавление задач:** автоматическая генерация уникального ID, валидация текста и фиксация даты создания (`add`).
- 📋 **Просмотр списка:** фильтрация только активных дел по умолчанию и режим полного вывода с флагом (`list --all`).
- ✅ **Отметка выполнения:** быстрый перевод задачи в статус завершённой (`done <id>`).
- 🗑️ **Удаление:** удаление задачи по ID с проверкой её существования (`delete <id>`).
- 💾 **Персистентность:** сохранение состояния в локальный файл `tasks.json` (данные не сбрасываются при перезапуске).
- 🛡️ **Защита от сбоев:** корректный перехват отсутствия файла (`try / except FileNotFoundError`) и валидация аргументов терминала.

## 🛠️ Стек технологий

- **Язык:** Python 3.12+ (поддерживает 3.10+)
- **Модули стандартной библиотеки:**
  - `sys` — парсинг аргументов командной строки (`sys.argv`);
  - `json` — сериализация и десериализация базы данных;
  - `datetime` — фиксация даты создания задач по стандарту ISO.
- **Внешние зависимости:** отсутствуют (Zero Dependencies).
- **Контроль версий:** Git (стандарт сообщений Conventional Commits).

## 📂 Архитектура проекта

Проект разделен на три изолированных слоя по принципу единственной ответственности (Single Responsibility):

```text
cli-task-manager/
├── .gitignore          # Исключение кэша (__pycache__) и локальной базы tasks.json
├── README.md           # Документация проекта
├── storage.py          # Слой персистентности: чтение и запись JSON на диск
├── tasks.py            # Слой бизнес-логики: создание, отметка, удаление и фильтрация
└── main.py             # Точка входа: CLI-интерфейс и диспетчеризация команд
```

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone git@github.com:Str1plexx/cli-task-manager.git
cd cli-task-manager
```

### 2. Запуск
Сторонние пакеты устанавливать не нужно. Программа готова к работе сразу:
```bash

```

## 💻 Примеры использования

```bash
# Справка по доступным командам
$ python3 main.py
Использование: python main.py [команда] [аргументы]
Команды: add, list, done, delete

# Добавление новой задачи
$ python3 main.py add "Пройти модуль по базам данных"
Добавлена новая задача!

# Просмотр активных задач
$ python3 main.py list
Список задач:
1. [ ] Пройти модуль по базам данных (2026-10-23)

# Отметка задачи выполненной
$ python3 main.py done 1
Задача выполнена!

# Просмотр всех задач (включая завершённые)
$ python3 main.py list --all
Список задач:
1. [x] Пройти модуль по базам данных (2026-10-23)

# Удаление задачи
$ python3 main.py delete 1
Задача удалена!
```
